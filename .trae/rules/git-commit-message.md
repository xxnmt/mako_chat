在此处编写规则，自定义 AI 生成提交信息的风格。
仅中文提交信息格式：

## 提交信息结构

```
<type>(<scope>): <中文描述>

<可选正文，仅中文>

<可选页脚>
```

## 类型定义 (Type)

| Type | 中文说明 |
|------|----------|
| `feat` | 新功能 |
| `fix` | 修复Bug |
| `docs` | 文档变更 |
| `style` | 代码格式 |
| `refactor` | 重构 |
| `perf` | 性能优化 |
| `test` | 测试相关 |
| `build` | 构建系统 |
| `ci` | CI配置 |
| `chore` | 杂项 |
| `revert` | 回滚 |

## 作用域 (Scope)

作用域用于指定提交影响的模块，可选项：
- `widget` - 主窗口组件
- `bubble` - 气泡组件
- `character` - 角色组件
- `image` - 图片资源
- `cmake` - CMake构建配置
- `git` - Git相关配置

## 格式规范

1. **标题行**: 不超过 72 个字符，仅用中文描述
2. **正文**: 每行不超过 100 个字符，仅用中文，解释"为什么"而不是"做了什么"
3. **页脚**: 用于标注 Breaking Change 或关联 Issue
4. **时态**: 使用现在时，而非过去时
5. **语言**: 除 `type`、`scope` 等格式关键字外，标题与正文一律只写中文，不附带英文翻译

## 示例

### 新功能
```
feat(widget): 添加窗口透明度控制

支持通过滑块调整主窗口透明度，范围10%-100%
```

### Bug修复
```
fix(bubble): 修复气泡闪烁问题

原因是定时器间隔过短导致重绘冲突
```

### 文档更新
```
docs: 更新README使用说明
```

### 构建配置
```
build(cmake): 升级Qt版本要求至6.5
```

### 杂项
```
chore(git): 添加.gitignore并清理构建产物
```

## 禁止事项

- 不要使用 `update`、`modify` 等模糊词汇作为 type
- 不要在标题行末尾加句号
- 不要在标题或正文中附带英文翻译
- 不要提交包含敏感信息的提交信息
- 不要使用 emojis（除非用户明确要求）
