# 统一检索与记忆感知 · P5 交接

更新于 2026-11-15。P0–P2 文档保留当时的实现与验证记录。

## 当前路径

Pet、QQ 私聊和 QQ 群的前台准备与六类搜索工具复用 MemoryRetrievalService。raw/chat 从本地索引读取；交谈摘要、长期摘要、claim、情景记忆、待整理输入与事项修订从各自的原表读取。原文参加词面与可选向量召回，结构化资料参加词面排名。来源、会话、工具权限和时间窗口在候选预算前生效。概览、展开已取得的句柄以及事项咨询保留各自的职责。

表达模型直接接收相关证据、当前认识与听众信息。群聊可以读取选定事项的修订原文、解释及版本。相关版本在生成期间改变时，程序刷新依据。承诺归属、回应关心、合法沉默、后台观察和真实渠道投递沿用各自的契约。

候选预算默认 40，重排后默认 10。配置 DashScope 后允许远程重排；已有配置显式关闭时继续使用本地排序。远程重排会发送获准候选的正文，其中可能包含摘要及其他派生资料。旧 legacy_fallback 字段已退役。打开辅助来源时，已授权的结构化记录独立于原文索引提供。配置见 [配置参考](CONFIG_REFERENCE.md)。

## 数据与回退

v16 在事务内为 raw、交谈摘要和情景记忆添加正文写入时间，历史行保持未知。既有索引与向量可以继续使用。升级前用旧版程序的 --backup-memory-db 保留一致性副本。需要回退时关闭应用，保留升级后的库，用旧二进制打开升级前备份。旧库原文索引为空时，以 --memory-index-status 检查，再使用 --rebuild-memory-index 或配置启动回填。已有块只缺向量时可用 --embed-memory-index 续算。

两个查询评测入口从只读连接复制数据库。自动检索、工具、事项咨询和最终表达都读取该题的临时副本。轮次上限同时限定聊天 ID 和该轮时间；提问时间更早时取更早的边界。claim 按更新时间判断，事项修订按记录时间判断。历史 raw 缺少实际入库时间时只能按发言时间筛选；旧交谈摘要、情景记忆缺少生成时间时会在截点回放中省略。当前值被覆盖且未保存历史版本时，也无法还原旧值。

## 验收记录

- 冻结位置为 build/benchmark/post_p5_baseline/。四组各 200 题，已将 800 份实际使用的答案逐一与判分文件中的 SHA-256 对照，包含首次失败后成功的 retry。冻结的 exe 是接手时留存的文件，历史作答时的二进制身份无法由这次冻结追溯证明。
- 隔离库测试加入截点后的 raw、互动摘要、长期摘要、回指早期事件的 claim 与事项修订，并检查源库仍可见两组记录。回环服务检查群聊表达请求可直接获得修订与本人原话。
- 四次真实记录回放均获得正文。主人 Pet 和私聊均提到努力调整作息，群聊记得脚踝恢复，回答仍有追加提醒或对时间的解释。非主人群聊未给出发图者，预设依据 chat/282:user 本身是提问，验证身份需要原始图片事件。最终构建产物在 build/benchmark/real_eval/p5_acceptance/。四题最终请求均含题设上海本地时间。此前回放曾将中午误认成凌晨；表达与时间解析现共用本轮接收时间。
- 本轮验收范围为工程与回放；现场 Pet、QQ 私聊和群聊另行验证。本轮未重跑 800 次或 714 题全卷，费用未取得完整账单。

Windows Debug 最终构建通过 15/15 个 CTest 套件。原基线的 832 个文件已复核哈希并与可执行文件一起归档于 build/benchmark/post_p5_baseline/baseline.zip。

## 评审收尾核查

本轮按用户批准执行工程收尾和小样核查，200 次问答暂缓，真实渠道现场验收另行安排。

- 已删除无调用方的 `searchHistoryTurns`。保留近期上下文的时间顺序、回复关联与概览能力。
- `MemoryReadPolicy` 为统一检索与近期上下文提供共同的盲区及当前隐私规则检查。原文索引重建与近期读取共用入站消息资格条件，排除敏感、脱敏、出站及空正文。近期读取在有效候选与有效群组计数前过滤；指定人物按解析后的身份匹配，兼容缺失 person_id 的旧消息。群组选择同时遵守时间窗上界。
- 回归用例覆盖敏感、脱敏、出站、当前隐私规则、盲区、其他人物和未来消息，检查这些记录不会挤掉预算内的有效消息。原有只读测试同时检查游标、摘要队列未被改变。
- 新四题产物、输入数据库副本、证据复核记录位于 `build/benchmark/p5_followup/`。`evidence_review.json` 保留实际进入最终请求的本人原文证据，按事实、人物、时间与披露分别复核。三条主人问题均有支持核心事实的直接报告，仍有重复关心、要求重复已知约定或从局部检索推断没有新约定的问题，判为部分通过。非主人发图者问题的预设引用是提问，且提问时间与历史截点相隔多日，判为无法评定，需要以原始图片事件和明确时间窗重新选样。
- 最终交付清单为 `build/benchmark/p5_followup/final/manifest.json`。记录基准提交与工作树差异、新增文件、构建配置、脱敏运行配置、二进制及测试和小样产物哈希。源码差异与新增文件随包保存，可在基准提交上恢复。本轮代码保留在工作树，后续提交后需补记提交关联；历史基线保留原身份。

小样的核心事实有证据支持不等于完整行为验收通过。本轮保留上述失败供后续开发定位，最终版本的固定 200 题及真实渠道质量仍待验证。`legacy_fallback` 已退役，旧字段读取时忽略、保存时移除。


## 2026-11-19：阶段 A 工程修复与受控回放

本轮范围：时间检索契约、检索状态、表达衔接诊断、TTS 生命周期、回归与交接。原 200/800 次问答暂缓，现场 QQ/Pet 验收仍另做。未修改正式配置、人格 prompt 或正式库内容，未运行全量重建。

### 时间工具

- schema 描述和解析器同时支持 relative_week + week_containing 省略 weekday；指定某一天仍要求 weekday。错误组合保留明确错误，不猜测用户想查哪天。
- recent_window 支持 1–44640 分钟，不能混入 span/period/occurrence；自然周、自然月与滚动窗口分别解析。整数拒绝小数和溢出，周偏移使用宽整数运算。
- interactions 的 ended_at 表示最后一条事件时刻。区间查询采用 started_at < to 且 ended_at >= from，修复恰好发生在起点的单条交谈漏计；上界仍排除。
- 临时库回归覆盖上下界、两个群隔离、跨年周、跨月周、闰年二月、星期和滚动七天。
- 真实 DeepSeek 原生工具小样：上周整周、上周三、上个月、最近七天均返回可执行参数。以 2026-11-16 10:00 上海为基准，范围分别为 11/9–11/16、11/11–11/12、10/1–11/1、11/9 10:00–11/16 10:00:01。滚动窗口沿用包含当前秒的上界约定。
- 该小样使用应用导出的工具 schema，调用 tool_choice=auto，再由 C++ MemoryRecallTool 执行模型参数；执行库为空的隔离库，用于验证契约和时间范围。历史内容与权限用临时数据测试覆盖。不能把这四次当作真实群历史总结正确率。

### 状态契约

| 字段 | 含义 |
|---|---|
| execution_status | complete=执行正常；degraded=某个执行环节降级；failed=不能正常执行 |
| truncated_by_limit | 候选/条数/字符预算被裁剪或达到预算边界；不能据此判定已有证据不够回答 |
| coverage_status | lookup/自动召回为 unknown；overview 对库内所选区间的扫描与聚合报告 complete/partial |
| coverage.basis | overview 覆盖统计基于 stored_interactions |
| coverage.historical_completeness | unknown：库内扫描完成不能证明现实历史完整 |

旧 status/partial/truncated 字段保留兼容。正常预算裁剪不再把执行 complete 改成 partial。Embedding 错误会记录降级原因并保留可用词面证据；工具逐来源保留检索执行报告，执行器传播降级。提示和日志同步解释三个维度。单项事实、最新状态、概览和不存在性问题仍有不同证据要求。

### 表达诊断：没有合入无效提示

成功表达调用 24 次：8 次探索；冻结每组记忆、只替换末尾用户话语的 8 次对照；相同记忆下追加候选通用提示的 8 次对照。群组比较无关游戏收尾/主动问及考试；私聊比较已躺下/报告新不适，每项重复两次。

基线群聊能避免主动提考试，也能在主动问及时引用既有状态。候选提示没有稳定改善私聊：依然出现确认头发是否干、补充未经本轮明确确认的完成状态。未合入该提示，未设置关键词分支或脚本答案。样本太小，且是应用捕获 prompt 的表达阶段重放，不是完整工具循环或现场验收；这些结果不能支持总体准确率或收益数字。后续应结合短期历史、派生认识和最终引用逐句核对，区分真实原话、旧助手表达及无依据细节，再选择有证据支持的修复。

### TTS 生命周期

mock 使用 MockTTSProvider，不创建进程管理器。api 启动失败时保留队列文字；设置改变时重建提供者，旧合成/PCM 回调受代次隔离。进程启动超时可取消，停止后健康探测不能使服务复活；只终止自己创建的 QProcess。外部端口占用报告失败并转文字，不杀占用者，也不自动接管。

测试使用模拟音频 sink 和可控测试子进程，覆盖 mock、失败、重试、停止/重启、端口归属、提供者切换与队列顺序。未实际加载 GPT-SoVITS 权重，音色、GPU 资源和真实音频播放不在本轮结论内。
