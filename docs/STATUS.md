## 2026-11-19 本轮工程与回放

本轮实施时间工具契约、检索状态语义和 TTS 生命周期修复。整周可省略 weekday，具体某天仍必须提供；滚动窗口支持最多 31 天。概览修复起点上单条消息漏计。自动检索和工具分别报告执行状态、预算裁剪与覆盖信息；正常 Top-K 裁剪不会自行使执行降级，完整历史覆盖仍不能由检索成功推断。

mock 不创建 GPT-SoVITS 进程；API 模式管理自己启动的进程，失败保留文字，切换提供者时作废旧回调。已有外部服务占用端口时不终止它，本次 API 启动失败并转文字。

表达诊断做了冻结记忆的成对回放，候选提示没有稳定改善关心收尾，未合入该提示。群聊无关近况与主动问及的对照样本能区分，但样本很小；私聊仍可能追加提醒或无依据补细节。M2 体验验收继续保留，不能写“关心收尾已稳定解决”。本轮未启动阶段 B 新开发。

详细结果、28 次成功真实模型请求与失败尝试、成本预留、构建关系见 [统一检索交接](RETRIEVAL_REFACTOR_STATUS.md) 最新小节。200/800 次问答继续暂缓；真实 QQ/Pet 现场另做。

## 接下来验收三件事

11 月 20 日续批已接入统一表达输出契约，以及 QQ 私聊/群聊按 TTS 相同句子单元逐条发送、回执串行和唯一请求编号。四组真实接口对照显示 claims 返回率改善，但仍有缺句、误分类与重复提醒；M2 不因此标为完成。QQ 验证使用本地 WebSocket，未代替现场验收。详见交接记录最新小节。

1. **A5 真实渠道复验**：同一句承诺在 pet、QQ 私聊、群聊各跑一次；确认承诺归属、关心收尾、群聊只确认所指且不公开无关背景。
2. **私聊归属/收尾实机**：确认“你答应过”只引用用户原话；用户说“已经躺下”后不再新增义务。
3. **活动真实使用**：写一段草稿 → 重启读回 → 继续写 → 写作中暂停 → 迟到回调不复活。
